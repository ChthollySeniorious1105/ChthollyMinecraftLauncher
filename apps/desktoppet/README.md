# DesktopPet 桌面宠物

Electron 桌宠：透明置顶的看板宠物 + 一个菜单按钮，点击打开功能窗口。

## 使用
- 运行 `dist/DesktopPet.exe`（便携版，无需安装）。
- 左键拖动宠物移动；单击互动；双击或点「⋯」按钮打开菜单；右键快捷菜单（大小、置顶、隐藏、退出）。
- 系统托盘图标：单击显示宠物，右键菜单可退出。
- 数据保存在 `%APPDATA%/DesktopPet/data.json`。

## 功能
- 桌宠：悬停显示快捷栏（喂食 / 玩耍 / 照顾 / 番茄钟）+「⋯」菜单按钮；需要照顾时头顶显示提示
- 宠物养成：饱食 / 心情 / 精力 / 清洁四项状态随时间下降；等级经验；小鱼干货币、商店、背包、每日签到（连签加成）
- 小游戏（获胜/结算都会奖励小鱼干）：扫雷、纸牌接龙、蜘蛛纸牌、空当接龙（均为 Windows 经典版规则）、俄罗斯方块、2048、
  数独（唯一解生成器）、五子棋（人机 AI 三档 / 双人）、中国象棋 / 国际象棋（人机三档，后台线程搜索）、日本麻将（三麻 / 四麻，简单 / 困难电脑，自动保存牌谱可回放）、翻牌配对、连连看（使用宠物立绘）、打砖块（12 关 + 无尽模式，16 种道具，TNT / 金币砖，连击与音效）、推箱子（25 关）、弹珠台、数织（30 道内置 + 宠物像素画）、贪吃蛇、宠物消消乐（宠物三消，直线 / 炸弹 / 同色特殊块，限时 / 限步）、四子棋（人机三档 / 双人）、打字雨（英文单词下落，WPM / 准确率，普通 / 禅模式）、24 点（只发有解的牌，提示 / 答案，计时 / 练习）、接食物（宠物提篮接美食，躲炸弹）
- 工具：番茄钟（后台计时、统计）、待办清单、便签、闹钟 / 倒计时、白噪音（WebAudio 合成，可叠加、定时关闭）、
  帮我决定（转盘）、系统监视（CPU / 内存）、记账本（预算 / 图表 / 导出 CSV）、习惯打卡（热力图）、计算器
- 快捷启动（程序 / 文件夹 / 网址）、全局快捷键 Ctrl+Alt+P 呼出菜单、节日日历（含农历）
- 键鼠映射看板（类 BongoCat）：全局监听键盘鼠标，SVG 小猫跟着敲键盘、握鼠标；猫猫桌面 / 完整键盘 / 邦戈鼓 / 钢琴猫 / 手柄 / 按键条，以及黑白简笔「线条猫」（键盘 / 键鼠 / 鼓 / 拍桌）、5 种花色、按键文字提示，Ctrl+Alt+B 召唤
- 每日任务：每天随机 3 个任务（喂食、赢游戏、番茄钟、钓鱼、探险等），完成各得小鱼干，全部完成额外 +20
- 外出探险：派宠物去公园 / 海边 / 森林 / 雪山 / 月球（按等级解锁），关掉程序也继续计时；回来带回小鱼干、食物和纪念品（20 件可收藏），外出期间桌宠变成半透明并显示倒计时
- 钓鱼：当前宠物坐在码头垂钓，场景随白天 / 黄昏 / 夜晚变化；抛竿 → 浮漂猛沉时收竿（会有轻啄干扰，秒收可“完美收竿”）→ 按住让绿框罩住鱼；连钓 3 条以上稀有鱼概率提升，今日鱼篓展示最近收获；16 种鱼（含夜行鱼、旧靴子）图鉴记录次数和最大尺寸，可用鱼饵提高稀有度，每天小鱼干上限 80
- 宠物花园：6 种作物（萝卜 → 南瓜，按等级解锁），按真实时间生长，关掉程序也会长；浇水后生长速度翻倍，成熟后宠物会提醒；6% 几率长出三倍价值的金色作物；可花小鱼干扩建到 8 块地
- 扭蛋机：每天免费扭一次，之后 10 小鱼干一次；24 款宠物手办（普通 70% / 稀有 25% / 珍贵 5%），15 次保底珍贵，重复手办返还 3 小鱼干
- 接食物：左右移动宠物用篮子接住苹果、小鱼干、饭团、蛋糕，躲开炸弹；星星双倍得分、爱心加命，连击越高分数倍率越高
- 主题：跟随 CML 启动器，在 CML 设置 → 外观 中切换；Hub 菜单、按钮、卡片和桌宠的气泡、快捷按钮一起实时换色（读取 `CML_THEME_FILE` 或 `%APPDATA%/CML/theme.json`，未安装 CML 时使用内置默认配色）
- 桌宠：可以把宠物扔出去（物理弹跳），节日当天有专属问候
- 健康提醒：喝水 / 久坐 / 护眼
- 20 只宠物可切换，大小/透明度调节，开机自启

## 开发
```
npm install
npm start          # 运行
npm run dist       # 打包 dist/DesktopPet.exe
```
若无法访问 GitHub，打包前设置：
`ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`

游戏/工具模块规范见 `src/hub/MODULES.md`。

作为 CML 内置应用发布时，由 CML 的共享 Electron 运行时以 `apps/runtime/electron.exe apps/desktoppet/app` 启动
（暂存脚本见 CML 仓库 `apps/build-apps.ps1`），数据目录仍为 `%APPDATA%/DesktopPet`。

排查问题：设置环境变量 `DESKTOPPET_DEBUG=1` 后运行，日志写入 `%APPDATA%/DesktopPet/debug.log`。
