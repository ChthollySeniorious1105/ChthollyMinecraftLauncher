# LumiKeyMapper

Windows 键盘、鼠标和滚轮映射工具。中文界面，配置只保存在本机。

## 直接运行

打开 `out/LumiKeyMapper.exe`（运行 `build.ps1` 生成，CML 启动器从这里打包）。这是 Windows x64 自包含单文件版本，无需另装 .NET；首次启动会解压随附运行组件，可能稍慢。

1. 点击右上角 **新建映射**。
2. 点击 **原按键** 的录入区域，然后按下并松开一个键、点击鼠标，或滚动滚轮。
3. 用相同方法录入 **映射为**。两个区域下方也都提供可选按键列表。
4. 在 **生效范围** 中选择 **全局**，或 **指定应用**（可从已打开窗口中选择），保存即生效。

初次启动没有默认映射，不会改变现有键位。

## 已支持

- 键盘、鼠标左 / 右 / 中键、两个侧键、滚轮上 / 下 / 左 / 右互相映射。
- 键盘与鼠标映射保留按住、松开行为。键盘自动重复会传递给目标键盘键或滚轮；目标鼠标键保持按住，不重复发送鼠标按下。
- 滚轮映射为键盘或鼠标时，每格短按一次；支持累计高精度滚轮的小步增量。
- 全局规则和按进程匹配的应用规则；可额外限制窗口标题包含的文字。
- 从当前已打开的应用窗口选择目标，或者手动填写进程名称。
- 默认按住 **左 Ctrl** 临时暂停，松开恢复；可在偏好设置中录入其他键盘键或鼠标按键。
- 新建、编辑、停用、删除规则，以及撤销最近一次删除。
- 搜索、范围筛选、总开关、系统托盘。
- 自动保存、JSON 导入 / 导出。导入前自动备份当前配置。
- 同一作用范围内的重复来源检查；暂停键不能同时作为映射来源。

## 界面

采用与 CML 启动器一致的 Fluent 风格无边框窗口：自绘标题栏（最小化 / 最大化 / 关闭，支持拖动、双击最大化和贴靠），左侧导航栏分为 **映射规则**、**设置**、**关于 / 帮助**。

- **映射规则**：顶部为搜索框、范围筛选（全部 / 仅全局 / 仅指定应用 / 仅已停用）、导入 / 导出，以及映射总开关和 **新建映射** 按钮。每条规则是一张卡片：键帽样式显示 `原按键 → 目标`（带键盘 / 鼠标 / 滚轮图标），旁边为名称和范围徽标（全局，或应用名 · 窗口标题），右侧为启用开关、编辑和删除按钮。停用的规则会淡化并标记“已停用”。没有规则时显示插图和“创建第一条映射”按钮。
- **规则编辑器**：在主窗口上方以模态卡片弹出（主窗口变暗）。两个大号“按下即录入”区域，录入时边框高亮并有脉冲动画；生效范围为分段按钮（全局 / 指定应用），选择指定应用后展开窗口选择器、进程名称和窗口标题条件。保存时校验重复来源、暂停键冲突等，错误显示在底部。
- **设置**：录入暂停键（不可选滚轮）/ 恢复为左 Ctrl、关闭时继续在托盘运行、打开配置文件夹 / 导入 / 导出，以及当前主题信息。
- **状态栏**：显示映射运行 / 临时暂停（按住暂停键时变为“临时暂停中”）/ 已停用状态、当前暂停键和保存状态。
- 删除规则后在底部弹出提示，可 **撤销删除**；其他提示和错误也在这里显示。

样式集中在 `LumiKeyMapper/Themes/Lumi.xaml`，所有颜色都通过 `DynamicResource` 画刷引用，可在运行时整体替换。

## 主题（跟随 CML 启动器）

界面不内置固定配色，而是读取 CML 启动器的主题文件：

1. 环境变量 `CML_THEME_FILE` 指定的 JSON 文件；
2. 否则 `%APPDATA%\CML\theme.json`；
3. 都不存在时使用内置浅色默认值（bg `#f4f7fa`、surface / panel `#ffffff`、text `#1d2233`、muted `#6b7280`、line `#e3e7ec`、field `#f3f5f8`、accent `#4fa3d9`、accent2 `#7fd3c8`、onAccent `#ffffff`）。

JSON 字段：`dark`（布尔）、`bg`、`surface`、`panel`、`text`、`muted`、`line`、`field`、`accent`、`accent2`、`onAccent`、`paper`、`ink`（均为 `#rrggbb`），以及 `id`、`name`、`version`、`art`。未知字段会被忽略；缺少的颜色按 `dark` 回退到内置浅色 / 深色默认值；悬停色、柔和强调色等派生色由这些颜色计算得出。托盘图标在启动时使用当前强调色。

`ThemeBridge`（`LumiKeyMapper/Services/ThemeBridge.cs`）用 FileSystemWatcher 监听该文件，约 150 ms 防抖后重新读取并实时更新界面。启动器先写 `theme.json.tmp` 再重命名的方式可以正确识别；文件被占用时会稍后重试；内容不完整或解析失败时保持当前配色不变。主题目录尚不存在时每 3 秒检查一次，创建后自动开始监听。

## 规则行为

映射以**当前前台窗口**为准，不向后台窗口发送按键。同一原按键同时匹配多条规则时，应用规则优先于全局规则，标题条件较长的规则优先；同等优先级按列表顺序。应用名称和标题匹配忽略大小写。

Lumi 自己的窗口内自动停用映射，以便保留修改和退出入口。编辑、录入、前台窗口切换、暂停、修改规则和退出时，会释放正在模拟按住的目标键。已被拦截的原按键在松开前不会突然恢复，以免产生多余输入。

录入只收集一个键；按下后松开即可完成。Esc 可以作为普通键被录入。10 秒内未完成会取消。暂停键需要能够按住，因此不能选滚轮。

按住暂停键时，该键本身也会正常发送给目标应用，例如左 Ctrl 暂停时 Ctrl+A 仍是原本的组合操作。将默认暂停键映射为其他键的来源前，须先修改暂停键。

关闭主窗口默认继续在系统托盘运行。右键托盘图标选择 **退出** 可完全停止；可在设置里关闭此行为。

## 配置位置

`%LOCALAPPDATA%\LumiKeyMapper\settings.json`

配置采用先写临时文件再替换的方式保存。发现损坏或不支持的配置时，会尝试备份原文件并以停用状态启动。导入备份为同目录下的 `before-import-日期时间.json`。软件不会记录输入内容，也不需要联网。

## 使用限制

- 当前是**单键到单键**映射，不包含一键发送组合键、连点宏、后台窗口输入或驱动级映射。
- 普通 Enter 和数字键盘 Enter 按 Windows 虚拟键视为同一键；左右 Ctrl / Shift / Alt 可分别录入。
- 软件必须运行才能生效。没有修改注册表键位，也不安装系统服务或驱动。
- 管理员应用通常需要以管理员身份启动 Lumi 才能映射。Windows 的 SendInput 受进程权限级别约束；发送失败会停用映射并显示原因。[Microsoft 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)
- Ctrl+Alt+Delete、安全桌面、拒绝模拟输入的软件或使用某些反作弊 / 原始输入机制的游戏不保证支持。
- 建议同一时间只运行一个重映射工具，避免不同工具互相处理模拟输入。

## 从源码构建

需要 Windows 和 .NET 10 SDK。应用采用 WPF + Win32 低级键鼠钩子，输入监听运行在独立消息线程，通过 SendInput 发送输出，并用标记跳过自身合成的事件。

```powershell
dotnet build LumiKeyMapper.sln -c Release
dotnet run --project LumiKeyMapper.Tests -c Release
dotnet run --project LumiKeyMapper.UiTests -c Release -- artifacts
```

运行 `build.ps1` 可以执行构建、核心测试、界面组件测试、离屏渲染检查，并把自包含单文件程序发布到 `out/LumiKeyMapper.exe`（`out/` 不纳入版本控制）。`-SkipTests` 跳过测试，`-SkipPublish` 只构建和测试。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

核心测试包括键盘 / 鼠标 / 滚轮转换、前台范围、暂停恢复、修改 / 删除规则、真实与模拟按键重叠、共享目标引用计数、配置校验及 100 组随机状态序列。

界面测试使用内存中的测试规则，验证筛选、导航、编辑视图、录入状态、重复来源校验，以及主题解析与文件监听（含 `.tmp` 重命名和不完整写入）；并以浅色和深色主题离屏渲染 `artifacts/*.png`。不保存测试规则或启用测试映射。此检查不等同于真实鼠标点击和外部应用端到端验收。
